# Безопасность

Не коммитьте секреты, токены, production data и `.env.local`. Любой `VITE_*` доступен посетителю приложения. Backend отвечает за permissions; frontend не является границей доверия.

Refresh token хранится в localStorage вместе с идентификатором сессии, а access token — в памяти. Пароли не сохраняются. Для защиты токенов от XSS избегайте вставки непроверенного HTML и используйте HTTPS в production. При смене аккаунта и выходе очищается кэш приватных запросов. Ротация токенов между вкладками координируется через Web Locks. MSW включается только в режиме разработки.

Уязвимости сообщайте владельцу репозитория приватно, без секретов и персональных данных в публичном issue. Канал связи будет определён владельцем при публикации репозитория. Обновления зависимостей проверяются вместе с lockfile, peer compatibility и quality gates.
