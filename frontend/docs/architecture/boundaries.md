# Границы

| Слой     | Допустимые зависимости                               |
| -------- | ---------------------------------------------------- |
| shared   | shared                                               |
| entities | shared                                               |
| features | entities, shared                                     |
| routes   | features, entities, shared; композиция route-модулей |
| app      | все слои; test/mocks только для dev bootstrap        |

Внутри модуля разрешены относительные импорты. Внешний импорт проходит через index.ts. Между features импорты запрещены; исключение требует одобренного design.md и узкого изменения lint rule. Entities также не зависят друг от друга. Routes содержат композицию, бизнес-логика живёт в features/entities.

ESLint local rule `architecture/boundaries` разрешает alias и относительный путь в абсолютный путь, проверяет направление и запрещает deep imports. CSS imports проходят проверку направления, но не требуют JS barrel. Test files могут обращаться к тестируемым внутренним файлам; production не может использовать этот обход. App имеет узкое инфраструктурное исключение для dev MSW. Generated types импортируются только внутри shared/api.

Нельзя импортировать DTO прямо как UI-модель при различиях смысла/формы. Добавляйте явный адаптер у доменного/feature boundary. Public index не должен становиться местом бизнес-логики.
