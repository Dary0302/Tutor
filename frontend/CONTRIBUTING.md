# Разработка

Перед изменением кода сверяйтесь с [архитектурными границами](docs/architecture/boundaries.md) и [стратегией тестирования](docs/testing/strategy.md).

Форматируйте изменённые файлы, запускайте затронутые тесты и проверяйте проект командой `pnpm verify` перед отправкой PR. Обновляйте lockfile вместе с зависимостями и следуйте [процедуре обновления OpenAPI](docs/api/openapi-workflow.md) при изменении контракта.
